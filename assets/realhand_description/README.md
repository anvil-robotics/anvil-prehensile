# Realhand Dexterous Manipulation Suite

The **Realhand Dexterous Manipulation Suite** provides high-fidelity hardware assets and digital twin solutions for advanced robotics research. This repository contains Universal Scene Description (USD) files specifically optimized for **NVIDIA Isaac Sim**, enabling seamless physical simulation and accelerated Sim-to-Real workflows.

## 🌟 Key Features

* **Precision USD Assets**: Optimized models for Realhand Dexterous Hands with accurate physical properties, collision meshes, and visual textures.
* **Isaac Sim Native**: Designed for direct integration into the NVIDIA Omniverse ecosystem.
* **Sim-to-Real Ready**: Fine-tuned joint dynamics and sensor configurations to minimize the reality gap.
